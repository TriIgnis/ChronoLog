# ChronoLog

Ubuntu 科研与学习 **Markdown 时间线日志软件**（v0.1）。

随时打开，快速记录。ChronoLog 自动带上当前日期与时间，把你的一条条记录追加到**当天的 Markdown 文件**里，形成清晰、可靠、可追溯的每日时间线。

- **记录优先**：一键呼出，秒级录入。
- **Markdown First**：所有正式日志都是标准 Markdown 文件，任何编辑器都能打开。
- **Local First**：数据默认保存在本地，不上云。
- **轻量化**：PySide6 + Qt6 原生组件，启动快、占用低。
- **数据可靠**：原子写入、文件锁、外部修改检测、草稿保护。

## 功能说明

### 快速记录（核心）
- 自动显示当前日期与时间（精确到秒）。
- 开始输入后固定本条记录时间，也允许手动修改记录时间。
- 标题 + Markdown 正文；正文有内容而标题为空时自动生成简短标题。
- 午夜跨日期场景正确处理：23:59 开始、00:03 保存，仍写入前一天文件。
- 快捷键保存/取消，加粗/斜体。
- 未保存内容自动暂存为草稿，异常退出后可恢复。
- 保存失败时保留输入内容，不丢失。

### 主窗口：每日时间线
- 启动默认显示今天；日历切换日期；已记录日期高亮。
- 按时间排序展示当天条目，显示时间、标题与渲染后的 Markdown。
- 点击条目编辑、删除（二次确认）；新增记录。
- 编辑/删除只改目标记录，检测外部修改，冲突时提示、绝不静默覆盖。

### Markdown 编辑器
- 源码编辑 + 预览模式切换。
- 语法高亮（标题、加粗、斜体、列表、引用、行内代码、代码块、链接）。
- 撤销/重做、复制粘贴、自动换行、字号调节。
- 中文与 Unicode 正常输入；LaTeX 原始 Markdown 完整保留。

### 全文搜索
- 扫描日志目录，搜索标题与正文，支持中文关键词。
- 后台线程执行，不阻塞界面；点击结果跳转到对应日期并定位条目。

### 悬浮球（一键快速记录）
- 桌面常驻圆形悬浮球，置顶显示、可拖动（位置自动记忆）。
- **左键单击**：立即呼出快速记录窗口。
- **右键菜单**：快速记录 / 打开主窗口 / 设置 / 退出。
- 可在「设置」中关闭；也作为全局快捷键的替代方案（无需系统配置）。

### 主题与设置
- 浅色 / 深色主题。
- 可配置：日志根目录、主题、编辑器字号、保存后是否自动关闭、启动行为、悬浮球开关。
- 配置与草稿遵循 Linux XDG 规范，不混入日志目录。

## Ubuntu 环境要求

- Ubuntu 20.04+（在 22.04.5 LTS 上验证）。
- Python 3.9+（在 3.11 上验证）。
- Python 依赖：`PySide6`（Qt6）、`markdown-it-py`。
- 图形桌面（X11 或 Wayland）。

## 安装方法

### 方式一：venv + pip（推荐）

```bash
cd ChronoLog
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
python -m chronolog
```

### 方式二：直接 pip 安装

```bash
cd ChronoLog
pip install .
chronolog --version
```

### 方式三：一键桌面集成安装脚本

```bash
./scripts/install.sh          # 普通安装
./scripts/install.sh --dev    # 可编辑（开发）安装
```

脚本会把启动器与图标安装到 `~/.local/share/applications` 与 `~/.local/share/icons`，使 ChronoLog 出现在 Ubuntu 应用菜单中，并可固定到 Dock。

### 方式四：Debian 包（best-effort）

```bash
./scripts/build_deb.sh
sudo dpkg -i dist/chronolog_0.1.0_all.deb
```

> `.deb` 只打包 ChronoLog 源码、launcher、`.desktop` 与图标，并声明依赖 `python3`；运行时仍需 `PySide6`、`markdown-it-py` 通过 pip 安装（或使用方式一的 venv）。

## 运行方法

```bash
chronolog            # 打开主窗口
chronolog --quick    # 打开快速记录窗口
```

开发环境亦可：

```bash
python -m chronolog
python -m chronolog --quick
```

### 单实例机制
重复运行 `chronolog` 会唤起已有实例（打开主窗口或快速记录窗口），不会重复启动多个进程。

### 全局快捷键
目标快捷键 `Ctrl + Alt + J` 用于快速记录。由于 Wayland 禁止应用自行注册全局快捷键，ChronoLog 不做需要 root 权限的键盘监听，而是建议在 Ubuntu 系统设置里手动绑定：

- 打开「设置 → 键盘 → 自定义快捷键」。
- 新建快捷键，命令填写：`chronolog --quick`。
- 绑定组合键 `Ctrl + Alt + J`。

> 更省事的方式：直接使用**悬浮球**（默认开启），鼠标点一下即可快速记录，无需配置快捷键。

## 日志存储位置

默认目录：

```text
~/Documents/ChronoLog/
├── 2026-11/
│   ├── 2026-11-12.md
│   └── 2026-11-14.md
├── 2026-12/
│   └── 2026-12-01.md
└── assets/
```

- 日期文件路径：`YYYY-MM/YYYY-MM-DD.md`，UTF-8 编码、系统本地时区。
- 可在「设置」中自定义日志根目录。

### 文件格式示例

```markdown
# 2026-11-14 星期六

<!-- chronolog:entry id=UUID timestamp=2026-11-14T09:30:15+08:00 -->

## 09:30:15 | 开始阅读论文

阅读 UAV-VLN 相关论文。

<!-- chronolog:end id=UUID -->

---
```

元数据用 HTML 注释保存，普通 Markdown 编辑器仍可正常阅读与编辑。

### 配置与草稿位置（XDG）

- 配置：`~/.config/chronolog/config.json`
- 草稿：`~/.local/share/chronolog/drafts/quick.json`

## 设置方法

主窗口右上角「设置」：

1. **日志根目录**：自定义日志存放位置。
2. **主题**：浅色 / 深色。
3. **编辑器字号**：8–40。
4. **保存后自动关闭快速记录窗口**：勾选后保存即关闭；否则保存后清空、可连续记录。
5. **启动行为**：主窗口 / 快速记录 / 上次使用。

## 常见问题

**Q：中文输入乱码？**
A：文件统一 UTF-8 编码；若用外部编辑器，请确保以 UTF-8 保存。

**Q：为什么外部修改了 Markdown 后无法保存？**
A：为避免覆盖，ChronoLog 检测到文件被外部修改会提示并重新加载。重新编辑后再保存即可。

**Q：快速记录窗口保存后去哪了？**
A：默认保存后自动关闭（隐藏）。可在设置中改为「保存后保持打开」。

**Q：全局快捷键无效？**
A：Wayland 下需手动在系统设置绑定 `chronolog --quick`，见上文。

**Q：日志文件被外部编辑器改动后看不到条目？**
A：ChronoLog 通过 HTML 注释定位条目；若外部编辑器删除了 `<!-- chronolog:... -->` 标记，该内容不会被解析为条目，但**绝不会被覆盖或删除**。请保留标记以便编辑。

## 已知限制（v0.1）

- 不实现：AI 总结、双向链接、知识图谱、云同步、Git 自动关联、工作时间统计、WYSIWYG、LaTeX 渲染、附件管理。
- 语法高亮为基础实现；预览任务复选框以 `[x]`/`[ ]` 原文形式展示。
- 全局快捷键需用户在系统设置手动绑定（Wayland 限制）。
- 搜索为简单文件扫描，数据量极大时建议后续升级为索引。
- 若正文中恰好包含 `<!-- chronolog:end` 这样的整行，可能干扰条目边界（极罕见）。
- 图形界面在无显示器环境以离屏方式验证；真实桌面渲染建议人工确认。
